# 阶段0：项目骨架提示词

> 适用场景：开新对话，一次性给全需求，让 AI 产出需求清单+技术方案+目录结构

## 提示词模板

```
你是一位资深的[前端/后端/全栈]工程师和产品经理。请帮我从零设计一个项目方案，我先描述我的想法，你帮我梳理清楚。

## 我的项目想法
[在这里描述你的项目：做什么、给谁用、解决什么问题]

## 我确定的技术栈
[例如：纯前端单文件HTML / Vue+Node / Python+Flask / 其他]

## 请你帮我产出以下内容（分项列出）

### 1. 需求清单
把项目拆成具体的功能点，每条格式：[编号] 功能名 — 具体描述 — 验收方式
（验收方式必须是可验证的，例如"点击保存后刷新页面数据仍在"）

### 2. 技术方案
- 用什么技术/框架/库，为什么
- 整体架构：有哪些模块，模块之间怎么交互
- 数据怎么存储（localStorage / 本地文件 / 数据库）

### 3. 目录结构
项目文件应该怎么组织，每个文件的职责是什么

### 4. 开发顺序
先做哪个模块，再做哪个，给出顺序和理由

## 要求
- 信息不足时，先列出3-5个问题问我，不要瞎猜
- 每个功能都要有可验证的验收标准，不能模糊
- 完成后先停下来，等我确认，不要直接开始写代码
```

## 使用要点

1. **一次给全**：把想法和技术栈一次说清楚，不要挤牙膏
2. **验收标准可验证**：不要写"用户体验好"，要写"点击保存后刷新页面数据仍在"
3. **人审后再继续**：AI 产出方案后，你必须确认，不要直接让它写代码
4. **信息不足时让它问**：明确要求"先问问题，不要瞎猜"

## 产出物检查清单

- [ ] 需求清单每条都有验收方式
- [ ] 技术方案说明了"为什么选这个"
- [ ] 目录结构每个文件有职责说明
- [ ] 开发顺序有理由
- [ ] 你已确认方案无误
