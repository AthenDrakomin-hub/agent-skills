## 聊天页核心布局

### 布局结构检查
- [ ] 聊天页高度是否撑满全屏（`100vh` → 替换为 `100%`）
- [ ] 消息列表区域是否占满中间剩余空间
- [ ] 输入栏是否固定在底部（`position: fixed; bottom: 0`）
- [ ] 顶部导航栏高度是否包含安全区

### 三端差异点
| 元素 | iOS 常见问题 | Android 常见问题 | H5 常见问题 |
|------|-------------|----------------|-------------|
| 消息气泡圆角 | 圆角过大/过小 | 圆角不一致 | 位置偏移 |
| 头像尺寸 | 尺寸不统一 | 尺寸不统一 | 尺寸不统一 |
| 时间戳样式 | 位置不对 | 颜色太浅 | 位置不对 |
| 已读回执 | 位置不对 | 位置不对 | 位置不对 |

### 检查方法
```bash
# 搜索聊天页文件
ls pages/ | grep -E "chat|message|im"

# 搜索输入栏相关代码
grep -rn "input\|textarea\|chat-input" pages/chat/ --include="*.vue" -l
```

## 输入栏与键盘适配

### 核心检查项
- [ ] 输入框字号是否 ≥16px（防止 iOS 自动放大页面）
- [ ] 键盘弹起时输入栏是否自动顶到键盘上方
- [ ] 表情面板切换时输入栏高度是否平滑过渡
- [ ] 语音输入按钮切换时输入栏高度变化是否正常
- [ ] 发送按钮在输入框有内容时才高亮

### pages.json 配置
```json
{
  "path": "pages/chat/chat",
  "style": {
    "app-plus": {
      "softinputMode": "adjustPan"
    }
  }
}
```

### 常见坑点
- [ ] iOS 上键盘弹起后页面不滚动到底部
- [ ] Android 上 `adjustResize` 导致输入栏被压缩
- [ ] H5 上软键盘弹出后地址栏遮挡输入框
- [ ] 表情面板打开时页面没有滚动到底部

## 消息列表与滚动

### 性能与体验
- [ ] 长消息列表是否做了分页/懒加载
- [ ] 新消息到达时是否自动滚动到底部
- [ ] 点击图片/视频消息是否有预览
- [ ] 消息列表下拉刷新是否正常
- [ ] 消息列表上拉加载更多是否正常

### 消息气泡样式
- [ ] 自己发的消息靠右，对方发的靠左
- [ ] 气泡最大宽度是否限制（一般 70%）
- [ ] 气泡圆角是否合理（一般 8-12rpx）
- [ ] 文字颜色在浅色/深色模式下都可读
- [ ] 时间戳居中显示，样式统一
