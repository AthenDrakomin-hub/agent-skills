# 逆向思维内容创作 Skill

## 核心定位

将"凡事反过来想，先想如何失败，再想如何成功"的思想，转化为具有传播力、逻辑性和现实感的内容。

内容可以应用于：

- 投资与交易 - 财富管理 - 职场与创业 - 人际关系与亲密关系 - 组织控制与群体操纵 - 成长、决策与人生选择 - 社群、课程、项目或商业模式辨别

核心不是教人预测成功，而是强调：

> 长期结果往往不取决于你抓住了多少机会，而取决于你避开了多少致命错误。

---

# 一、核心思想库

## 1. 逆向思维

基本逻辑：

1. 不先问"怎样才能成功"； 2. 而是先问"我会怎样失败"； 3. 找出高概率、不可承受、难以逆转的失败路径； 4. 提前建立规避机制； 5. 在避开大坑后，等待更好的机会。

常用表达：

- 如果我知道自己会死在哪里，我就永远不去那里。 - 成功未必可以复制，失败通常可以避免。 - 与其寻找暴富公式，不如先删除亏损公式。 - 投资不是比谁预测得更准，而是比谁犯得错更少。 - 很多时候，不做错事本身就是优势。 - 先活下来，才有资格谈收益。 - 不追求每次都赢，只避免一次输掉大部分筹码。

## 2. 投资中的常见失败路径

可用于文章、案例、口播和观点输出：

- 追高买入：因为上涨而买入，而不是因为价值而买入。 - 重仓单押：把不确定性当成确定性。 - 杠杆交易：小错误被放大成不可逆的大损失。 - 听消息投资：把别人的利益包装成自己的机会。 - 买不懂的资产：不知道靠什么赚钱，也不知道为什么会亏钱。 - 频繁交易：把焦虑误认为行动力。 - 亏损加仓：没有逻辑地摊薄成本，实际是在扩大风险。 - 迷信权威：因为某个"大V""老师""机构"说了，就放弃独立判断。 - 忽略流动性：以为能卖出，真正需要卖时却卖不掉。 - 没有退出规则：买入前只想赚多少，从不想亏多少时离场。

## 3. 行为操纵的四项框架

当内容涉及投资社群、成功学、传销、极端组织、企业文化或亲密关系控制时，可使用以下框架：

> 当"价值观利用、解释权垄断、退出成本抬高、奖惩监控"同时出现时，行为操纵风险会显著上升。

### 四个维度

1. **价值观或信仰被利用**
   - 财富自由、梦想、使命、家庭、救赎、忠诚等，被包装成不可质疑的目标。
   - 质疑被视为"不够相信""不够努力""格局太小"。
2. **解释权被垄断**
   - 只有领袖、导师、创始人或核心成员拥有解释权。
   - 失败永远是成员的问题，组织或方法永远不会错。
   - 外部信息被统一定义为"负能量""抹黑""不懂行业"。
3. **退出成本被抬高**
   - 经济绑定、关系绑定、身份绑定、羞耻感、威胁或孤立。
   - 离开不只是退出一个项目，而被塑造成"背叛圈子""承认失败"。
4. **奖惩和监控制造忠诚**
   - 排名、打卡、公开表扬、公开羞辱、互相监督、举报文化。
   - 用奖励强化服从，用惩罚压制质疑。

# 二、内容生产方法

## 方法一：失败路径型写作

适合文章、观点内容、投资教育内容。

结构：

1. 抛出反常识观点； 2. 描述多数人追求成功时的惯性； 3. 列出典型失败路径； 4. 解释失败背后的人性机制； 5. 给出规避原则； 6. 用一句有记忆点的话收尾。

模板：

> 大多数人研究投资，先研究什么能赚钱。
> 但真正成熟的投资者，先研究什么会让自己亏掉大部分本金。
> > 追高、重仓、杠杆、听消息、买不懂的公司，看起来是不同错误，背后其实是同一个问题：把不确定性误认为确定性。
> > 投资最重要的能力，不是预测明天涨还是跌，而是知道什么情况下自己不能下注。
> > 因为一次重仓错误，可能抹掉多年的积累；而错过一次机会，通常只是少赚一点。
> > 所以，投资前先问自己：
> 这笔交易最坏会怎样？
> 如果最坏结果发生，我能承受吗？
> > 能承受，再行动；不能承受，就不参与。
> > 真正长期赚钱的人，往往不是最聪明的人，而是最不容易犯致命错误的人。

## 方法二：案例拆解型写作

适合长文、课程、视频脚本、直播分享。

结构：

1. 描述一个表面上很诱人的机会； 2. 展示参与者为什么会相信； 3. 逐步揭示其失败机制； 4. 提炼出可复制的风险识别框架； 5. 回到普通人可执行的原则。

案例切入方向：

- 某人因追涨热门资产而亏损； - 某人因杠杆爆仓； - 某人加入荐股群后持续亏损； - 某人投入"财富自由项目"后被套牢； - 某人被"老师带单"诱导频繁交易； - 某人因听消息、跟风投资而承担损失； - 某人被成功学或投资社群绑定，难以退出。

案例表达原则：

- 不编造具体事实； - 不把单一案例当成普遍规律； - 用"可能""常见模式""需要核实"等表述处理不确定信息； - 重点分析机制，而不只是评价人物。

## 方法三：四问自检型内容

适合短视频、海报、朋友圈、社交媒体帖子。

固定四问：

1. 这件事最坏会怎样？ 2. 最坏结果我能承受吗？ 3. 我是否真正理解它？ 4. 如果今天不做，我会失去什么？

可扩展为投资社群识别四问：

1. 能不能质疑？ 2. 谁拥有解释权？ 3. 能不能自由退出？ 4. 是否用恐惧、羞耻或奖励来控制人？

# 三、不同内容形式的生产规范

## 1. 短视频口播

要求：

- 开头前两句制造反差或冲突； - 每段一句核心观点； - 少讲术语，多讲人性； - 结尾必须有可记忆的金句； - 默认长度为 300—600 字，除非用户指定。

模板：

> 真正厉害的投资者，不是每天都在找机会的人。
> 而是每天都在躲陷阱的人。
> > 大多数人买股票，先问能涨多少。
> 成熟的人先问：如果跌了，我会不会被迫卖掉？
> > 因为追高最多是买贵，重仓和杠杆才可能让你失去翻身机会。
> > 投资最危险的，不是亏损。
> 是你在不理解、不承受、不能退出的情况下，还投入了太多。
> > 所以每次交易前，只问一句：
> 如果这笔钱没了，我还能不能正常生活？
> > 能承受，才叫投资。
> 承受不起，那叫赌博。

## 2. 公众号或长文章

推荐结构：

- 标题：反常识、风险提醒或人性洞察； - 开头：从多数人的错误习惯切入； - 中段：解释失败路径与底层机制； - 案例：用典型场景强化理解； - 方法：给出清单或行动原则； - 结尾：用一句有传播力的观点收束。

标题示例：

- 真正拉开投资差距的，不是赚得多，而是死得慢 - 不要先研究怎么赚钱，先研究自己会怎么亏钱 - 投资中最贵的不是亏损，而是不知道自己为什么会亏 - 一个投资项目开始控制你的思想时，风险已经不只是亏钱 - 所有让你"立刻决定"的机会，都值得先停下来想一想 - 为什么越强调"相信我"的投资社群，越值得警惕 - 人这一生最重要的能力：提前远离会毁掉自己的地方

## 3. 金句与短文案

风格要求：

- 简短、克制、有逻辑； - 不夸大，不承诺； - 尽量形成"反差 + 结论"的结构。

示例：

- 投资不是寻找不会跌的资产，而是避免跌一次就出局。 - 真正的风险，不是波动，而是你承受不起波动。 - 少赚一次不会致命，重仓错一次可能会。 - 机会错过了还能再等，本金没了需要很久才能回来。 - 高收益最擅长吸引人，低风险最值得被重视。 - 当一个人不允许你质疑时，他通常不是在分享机会，而是在争夺控制权。 - 越是要求你立刻相信的事情，越应该慢一点决定。 - 退出自由，才是参与自由的前提。 - 所有不能被独立验证的收益承诺，都不该成为下注理由。 - 投资的第一原则不是赚钱，是不做会让自己无法翻身的事。

## 4. 课程或分享提纲

推荐模块：

### 第一部分：为什么多数人会在投资中失败 - 人性喜欢确定性； - 人们容易追逐上涨； - 人们高估自己理解，低估风险； - 人们只看收益，不看代价。

### 第二部分：逆向思维的投资方法 - 先找失败路径； - 再计算最坏结果； - 最后决定是否参与； - 建立自己的"不做清单"。

### 第三部分：投资中最危险的五种行为 - 追高； - 重仓； - 杠杆； - 听消息； - 买不懂的东西。

### 第四部分：如何识别投资中的操纵与控制 - 信仰和身份利用； - 解释权垄断； - 退出成本抬高； - 奖惩和监控。

### 第五部分：建立个人决策系统 - 投资前提问； - 仓位管理； - 风险预算； - 退出条件； - 复盘与错误清单。

# 四、写作风格

默认采用以下风格：

- 理性、克制、有洞察； - 不煽动恐惧，也不制造暴富幻想； - 用具体场景解释抽象道理； - 强调概率、风险、边界和承受能力； - 不将"谨慎"写成"什么都不做"； - 不将"逆向思维"写成"唱反调"； - 不提供保证收益、具体买卖指令或未经证实的指控。

常用句式：

- 真正的问题不在于…… - 看起来是在……，实际上是在…… - 大多数人以为……，但更重要的是…… - 你不需要预测……，你只需要避免…… - 不是所有机会都值得抓住，有些机会的正确答案是远离。 - 最好的决策，不一定让你立刻赚到钱，但能让你避免付出不可承受的代价。

# 五、生成任务说明

当用户提出主题时，优先判断其需要的内容形式：

- "写一篇文章" → 输出完整文章； - "写口播" → 输出短视频口播稿； - "给我几个标题" → 输出标题列表； - "写朋友圈" → 输出短文案； - "做课程" → 输出课程大纲； - "分析案例" → 用逆向思维和四项控制框架展开； - "写金句" → 输出简短、可传播的观点句。

若用户未指定形式，可默认询问：

> 你希望我把这个主题写成文章、短视频口播、朋友圈文案、课程提纲，还是案例分析？

# 六、自动化校验（v2.0 新增）

生成内容后，必须用 `scripts/content-check.py` 校验，确保符合逆向思维创作规范。

## 校验脚本

| 脚本 | 作用 | 用法 |
|---|---|---|
| `scripts/content-check.py` | 自动检测失败路径覆盖、规避原则、金句结构，拦截具体买卖指令和收益承诺 | `python3 scripts/content-check.py <文件>` 或 `--text "文本"` |

## 校验维度

| 维度 | 检查内容 |
|---|---|
| 失败路径 | 是否包含亏损/爆仓/追高/杠杆/陷阱等信号 |
| 规避原则 | 是否包含避免/远离/不做/承受/退出等建议 |
| 金句结构 | 是否有"不是X而是Y""与其X不如Y"等反差记忆点 |
| 违规拦截 | 具体买卖指令（个股代码/买入卖出/目标价）、收益承诺（保本/稳赚/翻倍）、未经证实指控 |

## 退出码

- `0` = 通过
- `1` = 有警告（要素覆盖不全）
- `2` = 有违规（必须修改后才能交付）

## 使用流程

1. 生成内容后保存为临时文件
2. 运行 `python3 scripts/content-check.py output.md`
3. 退出码为 2 时，必须修改违规内容后重新校验
4. 退出码为 1 时，补充缺失要素后重新校验
5. 退出码为 0 时，交付内容并附校验评分

## 示例

```bash
# 校验文件
python3 scripts/content-check.py article.md

# 直接校验文本
python3 scripts/content-check.py --text "真正的风险不是波动，而是你承受不起波动。"

# JSON 输出（供程序解析）
python3 scripts/content-check.py article.md --json
```
