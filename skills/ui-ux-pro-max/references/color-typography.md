## 色彩体系

### 色彩分类（禁止随意加色）
一套完整的界面色彩必须包含以下5类，每类控制在合理数量内：

| 分类 | 用途 | 数量建议 |
|------|------|----------|
| 主色(Primary) | 品牌色、主按钮、链接、选中态 | 1个 |
| 辅助色(Secondary) | 次要强调、图表辅助、装饰 | 1~2个 |
| 中性色(Neutral) | 文字、背景、边框、分割线 | 5~9个色阶 |
| 功能色 | 危险/成功/警告/信息 | 4个固定色 |
| 背景色 | 页面背景、卡片背景、悬浮层 | 2~3个 |

### 中性色阶（推荐9级）
```
--gray-50:  #F9FAFB   /* 最浅背景 */
--gray-100: #F3F4F6   /* 卡片背景 */
--gray-200: #E5E7EB   /* 边框/分割线 */
--gray-300: #D1D5DB   /* 禁用边框 */
--gray-400: #9CA3AF   /* 占位文字 */
--gray-500: #6B7280   /* 辅助文字 */
--gray-600: #4B5563   /* 次要正文 */
--gray-700: #374151   /* 正文 */
--gray-800: #1F2937   /* 标题 */
--gray-900: #111827   /* 重要标题 */
```

### 功能色（固定推荐值）
```
--danger:  #EF4444   /* 错误/删除/危险操作 */
--success: #10B981   /* 成功/完成/通过 */
--warning: #F59E0B   /* 警告/待处理/注意 */
--info:    #3B82F6   /* 提示/信息/一般链接 */
```

### 深色主题适配
- 深色模式背景色从 `#111827` 起步，文字从 `#F9FAFB` 起步
- 深色主题文字和背景对比度同样必须 ≥ 4.5:1
- 主色在深色模式下需降低饱和度（约10~20%），避免刺眼

## WCAG对比度校验

### 强制标准
- **正文文字**：对比度 ≥ 4.5:1（WCAG AA）
- **大字体（≥18pt 或 ≥14pt粗体）**：对比度 ≥ 3:1
- **UI组件边界/图标**：对比度 ≥ 3:1
- **深色主题**：同样适用以上标准，不得放宽

### 快速校验方法
计算两个色值的相对亮度比值：
1. 分别计算前景色和背景色的相对亮度 L
2. 对比度 = (L浅 + 0.05) / (L深 + 0.05)
3. 结果 ≥ 4.5 即为合格

### 常见不合格场景
- 浅灰文字（#9CA3AF）放在白色背景上 → 对比度约 2.8:1，不合格
- 主色按钮上的白色文字 → 必须验证主色亮度足够
- 禁用态文字 → 可适当降低标准，但需保持可辨识

## 排版系统

### 字体层级（移动端优先）
| 层级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| 大标题 H1 | 24px | 32px | 600 | 页面主标题 |
| 标题 H2 | 20px | 28px | 600 | 区块标题 |
| 副标题 H3 | 16px | 24px | 500 | 卡片标题、列表项标题 |
| 正文 Body | 14px | 22px | 400 | 主要内容文字 |
| 辅助文字 Caption | 12px | 18px | 400 | 说明、备注、时间 |
| 小字 Tiny | 10px | 14px | 400 | 标签、角标（谨慎使用） |

### 排版规则
- 禁止多字体混用，整套界面最多 1~2 种字体族
- 中文优先使用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 字间距默认正常，仅大标题可适当加宽（0.02~0.05em）
- 段落间距统一为 16px 或 24px，禁止随意数值
- 数字/英文与中文混排时保持合理间距

## 间距栅格

### 8px栅格体系
所有间距值必须是 4px 的倍数（推荐 8px 基准）：

```
--space-1:  4px    /* 极小间距（图标内边距） */
--space-2:  8px    /* 紧凑间距（图标与文字间距） */
--space-3:  12px   /* 小间距（列表项内间距） */
--space-4:  16px   /* 常规间距（卡片内边距） */
--space-5:  24px   /* 中间距（区块间距） */
--space-6:  32px   /* 大间距（页面区块间距） */
--space-7:  48px   /* 超大间距（整屏留白） */
```

### 边距规则
- 页面左右边距：移动端 16px，桌面端 24~32px
- 卡片内边距：统一 16px 或 20px
- 列表项垂直间距：12~16px
- 模块之间的间距：24~32px
- 禁止出现 7px、13px、19px 这类非栅格数值
