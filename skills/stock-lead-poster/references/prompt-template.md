## 风格一：红金笔刷金融引流风

### 完整生成Prompt

```
竖版股票引流海报，深色K线蜡烛图背景（红绿红绿K线，金融图表感），从上到下布局：

顶部第一行：红色笔刷笔触横幅底，上面是金色渐变大字【主标题1】，超粗黑体，立体效果

第二行：白色到金色渐变的超粗立体大字【主标题2】，字体有描边和阴影，右侧带一个红色向上箭头装饰

第三行：四个黑色圆角胶囊标签横向排列，每个标签前面有一个红色圆圈白色对勾图标，文字分别是：【标签1】、【标签2】、【标签3】、【标签4】

中间主体：3-4张白色资料样张倾斜叠放，有透视角度，看起来像翻开的文档。样张内容是K线图形态、股票案例分析表格，上面有红绿蜡烛图和文字标注

左下角：一个超大的红色圆角胶囊按钮，里面是白色粗体字"点击联系客服 即可免费领取"，按钮左侧有一个微信对话气泡图标，右下角有一个白色手指点击emoji和两个黄色小箭头装饰

右下角：一个黄色笔刷笔触底的矩形块，里面有三条带红色圆圈白色对勾的卖点文字，分别是：【卖点1】、【卖点2】、【卖点3】

整体风格：电商引流海报，高对比度，醒目吸睛，金融股票主题，竖版构图
```

## 风格二：蓝白商务应用推广风

### 完整生成Prompt

```
竖版App推广海报，蓝色渐变背景（浅蓝到深蓝渐变，干净明亮科技感），从上到下布局：

顶部左侧：一个白色圆角方形App图标 + 超大深蓝色粗体字【品牌名】，下面一行小字【品牌定位副标题】

顶部下面一行：三个蓝色圆角胶囊标签横向排列，白色文字，内容分别是：【信任标签1】、【信任标签2】、【信任标签3】

右上角：一个白色圆角卡片，顶部小字"同一家公司"，下面是【母公司Logo和名称】，再下面一个向下的连线箭头，分出两个小图标【关联产品1】和【关联产品2】
```

## 生成参数

- 模型：默认 seedream_5.0_flash
- 尺寸：width=750, height=1000（竖版，适配微信小店详情页）
- 如需横版Banner：width=750, height=400

## 编辑/微调

如需在参考图基础上修改文案，使用 `image_edit`：
- 风格一：`image_reference_url_list` 传入 `assets/reference-style.png`
- 风格二：`image_reference_url_list` 传入 `assets/reference-style-2-blue-app.png`
- prompt 描述要修改的部分，保持整体风格不变
