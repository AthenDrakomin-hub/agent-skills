# 引流海报生成

生成高转化率的竖版引流海报，核心目的是引导用户点击客服/下载/领取。内置两种成熟风格，按需选用。

---

## 风格一：红金笔刷金融引流风（参考图1）

**适用：** 股票资料免费领、K线图合集、金融知识引流

### 结构（从上到下7层）

1. **深色K线背景**：深黑/深蓝灰底，带红绿蜡烛图纹理
2. **顶部主标题**：红色笔刷笔触底 + 金渐变大字（如"免费领取"）
3. **第二行大标题**：白+金渐变超粗立体字，带红色向上箭头装饰
4. **标签胶囊行**：3-4个黑底圆角胶囊，每个前面红圈白对勾
5. **中间主体**：3-4张资料样张倾斜叠放，有透视感
6. **左下角CTA大按钮**：红色大圆角胶囊"点击联系客服 即可免费领取"，带微信图标、手指点击emoji
7. **右下角卖点列表**：黄色笔刷底 + 3条红圈白对勾

### 配色

- 主色：正红渐变 `#e53935 → #c62828`
- 强调：金/黄渐变 `#ffd700 → #ff8f00`
- 背景：深黑 `#1a1a2e` 带K线纹理
- 点缀：红对勾、黄箭头、微信绿

## 风格二：蓝白商务应用推广风（参考图2）

**适用：** App推广、企业产品引流、正规应用背书类海报

### 结构（从上到下7层）

1. **蓝色渐变背景**：浅蓝到深蓝渐变，干净明亮
2. **顶部品牌区**：左侧App图标 + 大标题 + 副标题（一行小字定位）
3. **信任标签行**：蓝色圆角胶囊标签，如"和抖音同一家公司 正规应用 安全可靠"
4. **右上角背书卡片**：白色圆角卡片，展示品牌关系（如"同一家公司" → 字节跳动 → 抖音/飞书）
5. **中间手机演示**：一部手机正面截图，展示应用商店详情页，关键数据用红色框/红色气泡高亮标注
6. **底部四卖点卡片**：2×2或1×4排列的白色圆角卡片，每个带蓝色图标 + 标题 + 副标题
7. **最底部CTA引导条**：浅蓝圆角底，左侧绿色下载图标 + 中间搜索框样式 + 右侧蓝色大按钮"下载安装"

### 配色

- 主色：科技蓝 `#1668dc → #40a9ff` 渐变
- 强调：红色高亮 `#ff4d4f`（用于关键数据、标注框）
- 背景：浅蓝白 `#f0f5ff` 到深蓝渐变
- 文字：深蓝/深灰为主，红色做重点
- 卡片：白色圆角，轻阴影

## 使用流程

1. 读取 [references/prompt-template.md](references/prompt-template.md) 获取两种风格的完整prompt模板
2. 根据用户需求选择风格一或风格二，替换文案变量
3. 调用 `image_gen` 生成竖版海报（推荐 750×1000 比例）
4. 如需微调，用 `image_edit` 对应参考图为锚点修改
