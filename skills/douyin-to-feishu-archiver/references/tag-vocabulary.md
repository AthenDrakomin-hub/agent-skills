# Tag Vocabulary

Approved tags for archived prompts. Keep tags lowercase, hyphen-separated, and consistent across all archives.

## Category Tags (pick exactly one)
- `frontend` — UI, CSS, JS frameworks, component design
- `backend` — APIs, databases, server logic, microservices
- `devops` — CI/CD, deployment, containers, monitoring
- `ai-ml` — LLM prompts, model training, agent workflows
- `content` — copywriting, video scripts, social media
- `product` — UX research, feature specs, PRD templates
- `security` — auth, encryption, vulnerability scanning
- `mobile` — iOS, Android, React Native, uni-app

## Platform Tags (pick 0–2)
- `vue`, `react`, `nextjs`, `nodejs`, `python`, `java`, `go`, `php`
- `docker`, `kubernetes`, `nginx`, `mysql`, `redis`, `mongodb`
- `feishu`, `douyin`, `wechat`, `telegram`

## Technique Tags (pick 1–3)
- `gsap`, `animation`, `scrolltrigger`, `parallax`
- `websocket`, `realtime`, `authentication`, `jwt`
- `prompt-engineering`, `few-shot`, `chain-of-thought`
- `testing`, `e2e`, `unit-test`, `visual-regression`
- `performance`, `optimization`, `caching`

## Rules
1. Maximum 5 tags per archived document.
2. Category tag is mandatory; platform and technique are optional.
3. Do not invent new tags without adding them to this file first.
4. When a video spans multiple categories, pick the dominant one and note the secondary category in the document body.
