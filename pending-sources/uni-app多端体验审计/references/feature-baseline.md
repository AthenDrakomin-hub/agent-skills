## 基础架构层

### 必备基础模块（所有项目都应该有）
- [ ] **请求封装**：统一的 request 封装，包含 baseURL、拦截器、错误处理
- [ ] **路由配置**：pages.json 完整配置，包含路由守卫
- [ ] **状态管理**：Pinia / Vuex 全局状态管理（用户信息、token 等）
- [ ] **工具函数**：utils 目录，包含常用工具方法（格式化、校验等）
- [ ] **常量配置**：api 接口常量、枚举值、配置项统一管理
- [ ] **环境配置**：开发/测试/生产环境区分

### 检查方法
```bash
# 检查是否有 request 封装
ls utils/request* api/request*

# 检查是否有状态管理
ls store/ store/index*

# 检查是否有环境配置
ls .env.* config/env*
```

## 网络请求层

### 完整的请求封装应该包含
- [ ] **baseURL 配置**：根据环境自动切换
- [ ] **请求拦截器**：自动携带 token、公共参数
- [ ] **响应拦截器**：统一处理错误码、token 过期、跳转登录
- [ ] **错误处理**：网络错误、超时、业务错误统一提示
- [ ] **loading 状态**：请求 loading 自动管理
- [ ] **重试机制**：失败自动重试（可选）
- [ ] **取消请求**：页面卸载时取消未完成请求

### 常见缺失项
- [ ] 没有统一的错误提示，每个页面自己写 toast
- [ ] token 过期没有统一处理，需要每个页面判断
- [ ] 请求没有超时设置
- [ ] 页面跳转后请求还在继续，导致内存泄漏

## 业务功能层

### 通用必备功能
- [ ] **登录/注册流程**：手机号登录、第三方登录、token 存储与刷新
- [ ] **退出登录**：清除本地缓存、跳转登录页
- [ ] **用户中心**：用户信息展示、编辑、头像上传
- [ ] **消息通知**：未读消息角标、消息列表

## 工程化与构建

### 项目结构规范
```
├── api/                 # 接口请求
├── common/              # 公共资源
│   ├── styles/          # 样式
│   ├── images/          # 图片
│   └── fonts/           # 字体
├── components/          # 公共组件
├── pages/               # 页面
├── static/               # 静态资源
├── store/               # 状态管理
├── utils/                # 工具函数
├── App.vue
├── main.js
├── manifest.json
├── pages.json
└── uni.scss
```

### 常见结构问题
- [ ] 图片散落在 pages 目录下，没有统一管理
- [ ] 公共组件放在 pages 里，没有抽到 components
- [ ] 工具函数写在页面里，没有复用
- [ ] api 接口写死在页面里，没有统一管理

## 性能与监控

### 性能优化项
- [ ] **分包加载**：主包体积控制在 2M 以内，合理分包
- [ ] **图片优化**：图片压缩、WebP 格式、懒加载
- [ ] **组件按需引入**：UI 组件库按需加载
- [ ] **代码压缩**：开启生产环境压缩
- [ ] **预加载**：常用页面预加载

### 监控与日志
- [ ] **错误监控**：全局错误捕获、上报
- [ ] **日志系统**：开发日志、生产日志区分
- [ ] **性能统计**：页面加载时间、接口耗时
- [ ] **用户行为埋点**：关键页面、关键操作统计

## 优先级排序

### P0 必须有
- 请求封装
- 登录鉴权
- 状态管理（用户信息）
- 环境配置

### P1 应该有
- 路由守卫
- 错误统一处理
- 工具函数抽取
- 公共组件抽取

### P2 可以有
- 性能监控
- 自动埋点
- 分包优化
- 骨架屏加载
