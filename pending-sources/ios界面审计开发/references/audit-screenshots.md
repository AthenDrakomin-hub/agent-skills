# 截图 / 录屏视觉走查指南

截图/录屏是症状证据，不是根因证据。走查结论按"区域标注 + 症状描述 + 嫌疑根因（置信度）+ 需查代码项"组织；根因需源码或 IPA 印证。乐享 tab 翻转案例见 `case-lexiang-tab-screenshot.md`。

## 1. 先要哪些截图（截图矩阵）

用户只给一张图时，一次性索要以下最小集（说清每个的作用，不要分多轮追问）：

**最小必测组合（3 机型 × 关键状态）**
1. iPhone SE（375×667pt，@2x，无 Home Indicator）—— 最小屏，暴露截断、固定高、空间不足。
2. iPhone 15/16/17 档（393–402pt 宽，灵动岛）—— 主流全面屏，查顶部安全区与底部热区。
3. iPhone Pro Max / Air（420–440pt 宽）—— 最大屏，查内容拉伸、可读宽度、栏悬浮。

**每个核心页面还要覆盖以下状态（在主流档截）**
4. 深色模式开关各一张（同页面对拍，查配色与图片深色变体）。
5. Dynamic Type 最大档（设置 → 显示与亮度 → 文字大小，拖到最右/辅助功能更大字体 AX5）—— 查截断、重叠、热区下移。
6. 键盘弹起（IM 聊天页必须，含输入框与最近消息可见性）。
7. 横屏（如声明支持）或明确写"锁定竖屏"。
8. RTL（阿拉伯语）截图，若声明支持或存在误触发史（乐享 tab 翻转前科）。
9. 空态 / 加载中 / 错误态（断网）/ 无权限态。
10. 启动屏（冷启动录像或首帧）—— 黑屏/黑边/启动图拉伸。
11. iPad Split View 或明确放弃 iPad（与 plist 声明交叉验证）。

补充证据：屏幕录制（滚动卡顿、栏收缩、键盘联动、按压反馈）> 静态截图；H5 套壳必须**真机**录屏（模拟器不代表 WKWebView 真实渲染和键盘行为）。

怎么截：Xcode 模拟器 Devices 窗口或 `xcrun simctl io booted screenshot x.png`；真机用 QuickTime / 截图；H5 壳在真机 Web Inspector 检查；用户自测时可以让其按矩阵拍。

## 2. 读图方法

1. **先认设备特征**：有没有灵动岛/刘海、有没有 Home Indicator、状态栏高度、几比几。
2. **画安全区框**：顶部灵动岛下方、底部小黑条上方、横屏左右圆角内侧是否有内容侵入；内容背景是否延伸到边缘（iOS 26 期望 edge-to-edge 背景 + 安全区内排版）。
3. **画网格/标尺**：左右边距是否一致且 ≥16pt；同行元素中心线是否对齐；间距是否落在 4/8 序列；列表行高是否 ≥44pt。
4. **逐元素读**：文字有无截断省略号/被裁、占位溢出、组件重叠、层级遮挡、圆角是否连续、分隔线左右 inset 是否统一。
5. **读状态**：选中态、禁用态、按压态、未读红点、连线/加载进度；颜色是否承担了唯一信息通道。
6. **读热区**：视觉小图标在屏上的命中盒是否 ≥44pt（按截图 pt 换算：截图 px ÷ 倍率；@3x 上 44pt = 132px）。
7. **对比系统**：同屏有系统栏（状态栏/键盘）时，自定义栏与系统栏在材质、圆角、边距、字重上是否协调；iOS 26 悬浮 tab 栏与自绘固定 tab 是否冲突。
8. **对比双模式**：浅色/深色对拍，逐元素比对；Dynamic Type 对比。
9. **读交互痕迹**：滚动位置（iOS 26 tab 栏应收缩）、内容是否从玻璃栏下方穿过。

## 3. 逐域检查清单

### 3.1 安全区与设备特征
- [ ] 顶部内容不进灵动岛/状态栏区域；状态栏时间/信号可读（背景与状态栏反差）。
- [ ] 底部固定控件在 Home Indicator 上方 ≥34pt 安全区或正确融合；横屏左右不贴圆角。
- [ ] 背景图/色延伸到边缘；只有文字/控件避开安全区。
- [ ] 启动首帧无黑边、无放大像素感、无上下 letterbox。
- [ ] 个人热点/通话状态栏增高时导航不崩（需运行时验证，截图无此态则列入待验）。

### 3.2 对齐、间距与布局
- [ ] 左右边距统一且遵循 readable width（大屏文字行宽不过长，建议 ≤42rem 或分栏）。
- [ ] 同组元素左缘对齐；头像、文字基線、尾部时间/箭头对齐。
- [ ] 间距为 4/8 序列；无随机 13px、5px 级混乱（允许单像素分隔线）。
- [ ] 圆角统一且用连续圆角；卡片阴影柔和且有 shadowPath（性能）。
- [ ] 旋转/分屏/大屏不拉伸变形、不留大片死白（用尺寸类重排而非等比拉宽）。

### 3.3 文字、截断与排印
- [ ] 无文字被裁、无非预期省略号（长昵称、群名、消息草稿）。
- [ ] 长昵称处理策略可见（省略号位置、尾部时间不被挤没）。
- [ ] 字号层级符合 Text Styles（标题/正文/辅助）；无大面积灰字低于 4.5:1。
- [ ] AX5 动态字体下容器纵向生长，不重叠不溢出（截图矩阵第 5 项）。
- [ ] 数字/时间格式无 `YYYY` 周年错误、无中英文/数字挤压（可结合源码 N-I18N-002）。

### 3.4 颜色、深色模式与材质
- [ ] 浅/深色各自语义色正确（背景层级、分隔线、占位灰）。
- [ ] 玻璃/模糊栏下方文字对比度达标；不是自造黑色 30% 蒙层。
- [ ] logo/插画/空态图有深色变体；输入框自动填充黄底处理。
- [ ] 品牌色在两种模式下都满足对比；状态色（成功/警告/错误）不依赖颜色 alone。

### 3.5 导航与系统栏
- [ ] 导航栏返回路径清晰；iOS 26 玻璃栏与内容 edge-to-edge；标签栏热区充足、滚动收缩正常（录屏）。
- [ ] 无"原生栏 + H5 栏"双导航/双 tab；标题居中/大标题策略一致。
- [ ] 分段控件/搜索框样式贴近系统；上下文菜单用原生样式（长按消息）。
- [ ] 全屏页面隐藏栏后有退出手段且不与灵动岛打架。

### 3.6 触摸目标、手势与反馈
- [ ] 所有可点元素 ≥44pt；相邻目标间隙 ≥8pt；边缘按钮留出边距。
- [ ] 图标按钮有无障碍标签（截图无法证明，列待验，结合源码/Accessibility Inspector）。
- [ ] 按压有反馈（高亮/缩放/haptic）；无点击无响应的装饰像按钮。
- [ ] 侧滑返回不被拦截；列表可侧滑操作（删除/置顶/免打扰）；聊天长按出菜单。
- [ ] 键盘上方输入栏跟随、发送键在键盘上方可达；空白处点按收起键盘。

### 3.7 滚动、性能与动效
- [ ] 滚动跟手、无明显掉帧（录屏；离屏渲染需 Instruments 确认，标注待验）。
- [ ] 分页/加载更多无跳动、无重复数据视觉；回到列表位置保持。
- [ ] 动效克制、可中断；系统"减弱动态效果"开启后降级。
- [ ] 头像/图片加载有占位、无尺寸跳动（CLS 类问题）。
- [ ] 骨架屏/loading 与真实内容布局一致，数据回来不跳。

### 3.8 状态完整性
- [ ] 空态：插画 + 说明 + 行动按钮，不是空白页；加载态用骨架屏且与真实布局一致。
- [ ] 错误态：原因 + 重试；无权限态：引导去系统设置。
- [ ] 消息状态（发送中/失败/已读/撤回/删除）视觉语义完整一致。
- [ ] 草稿、未读、置顶、免打扰、群 @ 提示在列表可见。

### 3.9 国际化
- [ ] RTL 截图：镜像正确（返回箭头、气泡尖、进度条、滑动方向），数字/电话/时间不镜像。
- [ ] 英文/长文案：按钮标题不截断、导航标题换行规则正确（Double-Length 伪语言可代替）。
- [ ] 中文页面绝无镜像翻转（乐享前科；一旦出现按 `audit-h5-source.md` §1 与案例文件定位）。

### 3.10 launch / 首启
- [ ] 启动屏与首帧背景一致，无白闪/黑闪、无 Logo 跳动（Launch 与首帧同底色同 Logo 位置）。
- [ ] 引导页/隐私弹窗可点区域达标、隐私入口在、不阻断审核路径。

### 3.11 iPad / 横屏（如适用）
- [ ] 用宽度而非拉伸：列表/详情分栏或居中限宽；Split View 各档可用。
- [ ] 横屏安全区四向正确；键盘形态（浮动/拆分键盘）下输入仍可见。

## 4. IM 场景专项

| 页面 | 重点隐患 |
| --- | --- |
| 会话列表 | 长群名截断策略、时间右对齐不被挤掉、草稿/未读数/置顶背景、@ 提示颜色不唯一、滑动操作热区、离线/连接状态 |
| 聊天页 | 气泡最大宽度 70–75%、文字选中复制、长按菜单、引用/回复缩进、时间分隔条、自己/对方气泡配色对比、底部输入栏安全区与键盘联动、+ / 语音 / 表情热区 44pt、图片消息占位与加载失败态、语音条长度语义、群昵称颜色区分但不依赖颜色 |

## 5. 诊断报告模板（标注式）

对每一处问题在脑内/报告里用字母标注截图区域（A、B、C…），按下表输出：

```
【截图信息】机型/系统版本/倍率/浅色或深色/动态字体档位/是否横屏
【区域 A】症状：…（客观描述所见，不猜原因）
【根因嫌疑】…（对应规则号，如 H-SAFE-001 / N-DARK-001；置信度：高/中/低 + 依据）
【需查代码】文件模式/grep 关键词 / plist 键 / 需补拍的状态截图
【修复】代码或配置（完整可落地）
【验证】真机/模拟器回归点
```

## 6. 置信度规则

- **高**：症状与某根因强一一对应且截图含直接证据（如同时看到镜像文字与反向排列 → RTL；底部固定栏与小黑条重叠 → 安全区）。
- **中**：症状对应 2–3 个候选根因（如文字截断可能是固定行数、固定高、未适配动态字体），列出全部候选与排查顺序。
- **低**：仅凭截图无法定位（颜色值、对比度数值、约束关系、代码逻辑），明确写"需查代码/工具验证"并给出方法，不编造结论。
- 任何 P0/P1 结论在交付前争取第二通道印证（源码 grep、IPA 键值、运行时工具输出）。
